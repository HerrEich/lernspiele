Wie speichert ein Computer Buchstaben?

Ein Computer kennt im Inneren nur Nullen und Einsen (Strom an oder aus). Um Buchstaben wie A, B, C zu speichern, haben Informatiker weltweit eine feste Vereinbarung getroffen: den ASCII-Code (American Standard Code for Information Interchange).

Der Großbuchstabe A hat als Startpunkt immer die Kennzahl 65. Im Binärsystem ist das genau: 64 + 1 = 65 (Binärcode: 01000001).

Probiere den Startpunkt sofort aus:
A
Dezimal: 65 | Binär: 01000001

Die Alphabet-Leiter: Es zählt einfach aufwärts!

Das Geniale an ASCII ist: Die Großbuchstaben folgen exakt der Reihenfolge des Alphabets!

Wenn A = 65 ist, dann ist B = 66 ($65 + 1$), C = 67 ($65 + 2$), D = 68 ($65 + 3$) und so weiter!
